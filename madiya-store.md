# Madiya Store

**Luxury E-Commerce Website · Client Project Portfolio Case Study**

## Overview

Madiya is a custom Persian RTL e-commerce website built without WordPress. The project combines a product-focused storefront with product search, filters and sorting, shopping cart, customer accounts, order tracking, and a dedicated administration panel.

## My Contribution

- Product catalog, filters, sorting, cart, and customer account workflows
- Administration panel for products, categories, orders, customers, pages, policies, shipping methods, and site settings
- cPanel-ready deployment, guided installation, security controls, and handoff documentation

## Implementation Notes

The store supports product filtering and sorting by criteria including price, weight, name, date, stock, type, material, and suitability. The current delivery uses an unpaid-order workflow and does not include an online payment gateway.

The application targets PHP 8.2+ with MySQL/MariaDB. Installation creates the application configuration and database structure, generates initial administrator credentials, and requires the administrator to change credentials after first login.
